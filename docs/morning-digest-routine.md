# 朝刊ダイジェスト Routine 設定メモ

毎朝の news digest を自動送信するための設定。claude.ai の Routines
（スケジュール実行）に登録して使う。

## スケジュール

- 毎日 07:00 JST → cron (UTC): `0 22 * * *`
  - JST は UTC+9 なので 07:00 JST = 前日 22:00 UTC。日付がまたぐ点に注意
  - 時刻にこだわりがなければ `57 21 * * *`（= 06:57 JST）を推奨。毎時0分は
    世界中のジョブが集中するため、数分ずらすと詰まりにくい
- 「新しいセッションを毎回作る」モードで登録すること（過去の会話を引き継がない）

## 既知の失敗と対策（2026-09-12 の実配信より）

初回の自動配信で3つ壊れた。プロンプト側で潰してある。

1. **日付が1日ずれた**。実行環境のシステム時計が UTC のため、23:13 UTC
   （= 9/12 08:13 JST）に走ったジョブが「今日は9/11」と判断した。見出しも
   対象期間も9時間ずれた。→ 冒頭で JST を実測させる。
2. **F1 が誤報**。今週末に決勝があるスペインGPを飛ばし、前々戦のイタリアGPを
   最新扱いして「次戦はアゼルバイジャン」と書いた。検索ではなく記憶で
   埋めた結果。→ 日程・結果は必ず出典で裏を取らせる。
3. **出典リンクが punycode 化した**。「ファミ通.com」等の日本語ドメインを
   本文にベタ書きしたため。→ 必ず `<a href>` を使わせる。

## Routine に貼るプロンプト

以下をそのまま Routine の prompt 欄に入れる。毎回まっさらなセッションで
実行されるため、前提を含めた完結した指示になっている。

---

### 最初にやること（必須）

Bash で `TZ=Asia/Tokyo date '+%Y-%m-%d %H:%M %A'` を実行し、JST の現在日時と
曜日を確認する。**実行環境のシステム時計は UTC のことがあり、JST とは日付が
ずれる。** 見出しの日付・曜日・対象期間は必ずこの JST の実測値を使うこと。
システム日付や記憶上の日付をそのまま使ってはいけない。

確認した JST 日付を基準に、対象期間を明示的に決める（過去24時間、月曜のみ
過去72時間）。

### 本文の作成

`daily-news-digest` というスキルを Skill ツールで読み込み、その手順・枠配分・
選定ルール・フォーマットに従って本文を作る。版は朝刊。

スキルへの追加指定:

1. スキルの6ジャンルの前に「一般ニュース」枠（最大3件）を置く。国内外の主要
   トピックを扱い、一次情報（官公庁・日銀・企業の公式発表、通信社）を優先する。
   まとめサイト・個人ブログ・SEOランキング記事は使わない。該当がなければ
   「今日はなし」と1行書く。
2. 出典は URL の直書きではなく、出典名のリンクにする。

### 記憶で書かない（重要）

日程・結果・順位・価格・発売日は、**必ず対象期間内の出典で裏を取る。**
裏が取れないものは載せず「未確認」と書く。特に次の2点で事故が起きやすい:

- **F1**: 「今週レースがあるか」を最初に確認してから書く。直近レースの結果
  だけを見て次戦を推測しない。開催週なら決勝の日時（JST）を必ず入れる。
- **サッカー**: リーグ戦・CL/EL の節が対象期間に掛かっているかを確認する。
  「今節開催なし」と書く前に、その週末の日程を見る。クラブの所属大会
  （CL か EL か）も毎回出典で確認する。

### 配信

`mcp__Gmail__send_message` で prince.totti.no10@gmail.com 宛に送る。

- 件名: `【YYYY年M月D日(曜) 朝のニュース】`（JST の実測値を使う）
- `htmlBody` と `body` の両方を入れる
  - `htmlBody`: HTML版。出典は必ず `<a href="URL">出典名</a>` の形にする。
    **「ファミ通.com」「価格.com」のような日本語・非ASCIIのドメイン名を本文に
    そのまま書かない**（メール側で punycode に変換され壊れたリンクになる）。
    スタイルは全てインライン指定（メールクライアントは外部CSSも `<style>` も
    読まないことがある）。横幅は max-width 640px、背景色と文字色は明示指定
  - `body`: プレーンテキスト版。こちらは URL をそのまま書く
- 送信後、何ジャンル・何件送ったかを1行で報告する
- ファイルやアーティファクトは作らない

### ntfy は使わない

ntfy.sh はこの実行環境の egress ポリシーで CONNECT が 403 拒否される。
試すだけ無駄なので使わない。

### 失敗時

Gmail 送信が失敗したら、リトライは1回まで。それでも駄目なら
`mcp__Gmail__create_draft` で下書きとして残したうえで、ダイジェスト本文を
全文そのままターミナルに出力し、「Gmail送信失敗（理由）」と明記する。
黙って諦めない。

---

## 恒久化の残件

`daily-news-digest` スキル本体は claude.ai 同期スキル。ローカルで書き換えても
次の同期で上書きされる。上記「スキルへの追加指定」「記憶で書かない」を
スキル本体に取り込むなら claude.ai 側で編集する必要がある。それまでは
この Routine プロンプト側で指定しておけば動く。
