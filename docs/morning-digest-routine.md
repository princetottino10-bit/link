# 朝刊ダイジェスト Routine 設定メモ

毎朝の news digest を自動送信するための設定。claude.ai の Routines
（スケジュール実行）に登録して使う。

## スケジュール

- 毎日 07:00 JST → cron (UTC): `0 22 * * *`
  - JST は UTC+9 なので 07:00 JST = 前日 22:00 UTC。日付がまたぐ点に注意
  - 時刻にこだわりがなければ `57 21 * * *`（= 06:57 JST）を推奨。毎時0分は
    世界中のジョブが集中するため、数分ずらすと詰まりにくい
- 「新しいセッションを毎回作る」モードで登録すること（過去の会話を引き継がない）

## Routine に貼るプロンプト

以下をそのまま Routine の prompt 欄に入れる。毎回まっさらなセッションで
実行されるため、前提を含めた完結した指示になっている。

---

`daily-news-digest` スキルを Skill ツールで読み込み、その手順・枠配分・選定
ルール・フォーマットに従って本文を作る。

版: 朝刊（対象期間は過去24時間、月曜は過去72時間。基準はJST）

### スキルへの追加指定

1. スキルの6ジャンルの**前に**「一般ニュース」枠（最大3件）を置く。国内外の
   主要トピックを扱い、一次情報（官公庁・日銀・企業の公式発表、通信社）を
   優先する。まとめサイトやアフィリエイト記事は使わない。該当がなければ
   「今日はなし」と1行書く。
2. 出典は URL の直書きではなく、**出典名のリンク**にする。

### 配信

Gmail で prince.totti.no10@gmail.com 宛に送る。`mcp__Gmail__send_message` を使う。

- 件名: `【YYYY年M月D日(曜) 朝のニュース】`
- `htmlBody` に HTML 版、`body` にプレーンテキスト版を両方入れる
  - HTML 版: 出典名を `<a href="...">出典名</a>` にして URL を表に出さない。
    スタイルはインライン指定（メールクライアントは外部CSSを読まない）
  - プレーンテキスト版: URL をそのまま書く（HTML を切っている環境向け）
- 送信後、何ジャンル・何件送ったかを1行で報告する

### ntfy は使わない

ntfy.sh はこの実行環境の egress ポリシーで CONNECT が 403 拒否される。
試すだけ無駄なので使わない。将来 `ntfy.sh` が許可ホストに追加され、かつ
実トピック名が決まったら、この項を書き換える。

### 失敗時

Gmail 送信が失敗したら、リトライは1回まで。それでも駄目なら
`mcp__Gmail__create_draft` で下書きとして残し、ダイジェスト本文を全文
ターミナルに出力して「Gmail送信失敗（理由）」と明記する。黙って諦めない。

---

## 恒久化の残件

`daily-news-digest` スキル本体は `~/.claude/skills/synced/` にある claude.ai
同期スキル。ローカルで書き換えても次の同期で上書きされる。上記「スキルへの
追加指定」の2点をスキル本体に取り込むなら、claude.ai 側でスキルを編集する
必要がある。それまではこの Routine プロンプト側で指定しておけば動く。
