# マッシュアップ（既存ゲームを混ぜる）の方法

## 手順

1. **分解する**：各ゲームを次の表に書き出す。

| 項目 | ゲームA | ゲームB |
|---|---|---|
| 盤面（どこに何を置く） | | |
| 手番（1 手番で何をする） | | |
| 勝ち方 | | |
| 味＝そのゲームらしさの仕組み（2〜3 個） | | |
| 核の瞬間（一番盛り上がる場面） | | |

2. **骨格を 1 つ選ぶ**：手番の流れと勝ち方は、どちらか一方をベースにする（両方混ぜると手番が重くなる）。
3. **味を 1〜2 個ずつ移植する**：もう一方の味を、骨格の言葉に翻訳して入れる。
   - 例：Compile の「プロトコルと同じレーンにしか表で出せない」＋ Smash Up の「ベースを取り合う」→ レーンにプロトコルを置き、中央にベースを置く
4. **衝突を解く**：2 つの仕組みが同じ役割をしていたら片方を消す。勝ち方が 2 つになったら、片方を「特殊勝利」として残すか統合する。
5. **核の瞬間が両方残っているか確認**：A の盛り上がりと B の盛り上がりが、1 ゲーム中にどちらも起きるか。

## よくある失敗

- 全部の仕組みを足して、ルールが 2 倍になる → 「この仕組みを消したら何がつまらなくなる？」と聞いて、答えられないものは消す
- 片方のゲームの「名前だけ」借りて、味が残っていない
- 既存ゲームのカード名・イラスト・固有用語をそのまま使う → テーマや仕組みは参考にしてよいが、名前と文章はオリジナルにする

## 参考：分解例

| | Compile | Smash Up |
|---|---|---|
| 盤面 | 3 レーン、各レーンに両者のプロトコル | 場にベース数枚、ミニオンを置く |
| 手番 | 1 枚出す or 手札補充 | ミニオン 1 + アクション 1 |
| 勝ち方 | 3 プロトコルをコンパイル | 15VP |
| 味 | 表/裏プレイ（裏は値 2・正体隠し）、出せるレーンの制限、カードの重なり | 2 派閥を混ぜたデッキ、ベース破壊の 1 位/2 位/3 位 VP、派閥ごとの個性 |
| 核の瞬間 | 裏向きを表にしての逆転、コンパイル直前の攻防 | 意外な派閥コンボ、ベース破壊時の順位争い |
