# 多人数戦（3〜4 人）の設計

出典・実例は research-report.md の「4人対戦では『誰を攻撃できるか』と『待ち時間』が最大の設計変数になる」章。

## 3 つの失敗要因

| 失敗要因 | 何が起きるか | 主な対策 |
|---|---|---|
| キングメイキング | 勝ち目のない人の手が勝者を決める | Wiersma の 3 条件のどれかを崩す（下記）、チーム戦 |
| リーダー叩き | 先頭が全員に殴られ続け、争いに加わらない人が漁夫の利 / 終わらない | 攻撃対象を場所単位・自動対象に、得点の部分的な非公開、先頭を叩く行動が自分の得にもなる形 |
| ダウンタイム | 自分の番まで待つ。1 手番 2 分×3 人＝6 分待ち | 同時選択・一斉公開、他人の手番中の判断（リアクション）、手番を短く |

関連：亀戦法（盤面が人数に対して広いと起きる）、サンドバッギング（標的にならないよう好調を隠す）。デザイナー調査では最悪の問題はキングメイキング 42%、リーダー叩き 23%。

## キングメイキングは「完全には解けない」

Jaffe（GDC 2019）はこれを「呪われた問題」と呼ぶ。プレイヤーへの約束同士がぶつかるので、約束そのものを変えて回避する。4 つの技法：
- **Barriers**：約束破りにつながる行動を制限する
- **Gates**：成功・得点を隠す
- **Carrots**：2 位以下にも報酬を出す
- **Smores**：ゲーム自体を楽しくして交渉の道具を与える（政治を楽しむ方向）

**Wiersma の「最悪のキングメイキング 3 条件」**——どれか 1 つを崩せば影響が減る：
1. その人の手が他者間の勝敗を決める
2. どの手を選んでも本人の順位は改善しない ← 全順位に得点を配れば崩れる
3. 本人がそれを自覚している ← 得点を部分的に隠せば崩れる

## 対象指定の書き方（4 人カードゲームで最も効く変数）

| 書き方 | 政治・ヘイト | 使いどころ |
|---|---|---|
| 共有の場所（基地・レーン）単位 | 低 | 基本形。「誰を殴るか」ではなく「どこに置くか」の競争になる |
| 各対戦相手（全員） | 低 | 公平。効果が 3 倍になるので数値は小さく |
| 隣席限定（左/右） | 低 | 追う範囲が狭く政治が消える（7 Wonders の軍事） |
| 対戦相手 1 人を選ぶ | 高 | ドラマは出るが報復と先頭叩きを生む。少数に絞るか「最も得点が高い人」など自動対象に |
| 役職・役割を指定 | 中 | 間接的になる（Citadels の暗殺者） |
| 強制攻撃 | — | 「〜せよ」ではなく「〜すれば報酬」の形にする |

## 4 人で好評な作品の共通点

次の 3 つのうち 2 つ以上を満たしている：
- **同時性**（待たせない）：7 Wonders、Sushi Go、Libertalia
- **他人の手番中の意思決定**：Coup のチャレンジ、Cosmic Encounter の同盟
- **先頭が誰か曖昧**：Ticket to Ride の非公開チケット

脱落は「1 ラウンド数分」のときだけ許される（Love Letter は OK、Bang! は最大の批判点）。

## チーム戦（2 対 2）

- 全員が最後まで勝敗に関与するので、キングメイキングが構造的に消える
- 典型形：**勝敗資源は共有、行動資源は個別**（MTG 双頭巨人戦：ライフ共有、手札・マナは個別、チーム同時にターン）
- 1 人がチームの判断を支配しがち → 手札の非公開、会話・合図の制限
- スマホでは 1 画面に見せる盤面を絞る（Battlegrounds Duos を 2 人チームに留めた理由）

## 席順

- MTG 統率者戦 4 人卓約 24.4 万試合：1 番席 29.2%、2 番席 25.7%、3 番席 23.6%、4 番席 21.5%
- Agricola は 2 番席が有利 → **傾向はゲームごとに違うので自作で測る**
- 補正の例：初手の逆順、後の席に初期資源、同点なら後の席の勝ち。補正後に必ず測り直す

## 人数でスケールさせる

- 場所の数を人数＋1 にする（Smash Up は 4 人で 5 基地）、盤面を削る（Brass の 2 人戦）、人数別の初期値
- テストは対応人数すべてで行う
