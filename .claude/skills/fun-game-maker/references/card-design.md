# カード・勢力の設計

出典・実例は research-report.md の「カードは『深さ÷複雑さ』で評価し、勢力は『できないこと』で定義する」章。

## Rosewater「ゲームに必要な 10 のこと」（土台チェック）
目標 / ルール / 相互作用 / 追い上げ要素 / 慣性（確実に終わる） / 驚き / 戦略 / 楽しさ / フレーバー / フック（教えるより興味を引く）

## Rosewater「20 年の 20 の教訓」からカードに効くもの
- 人間の本性と戦うのは負け戦
- 「興味深い」と「楽しい」を混同しない（プレイヤーはカードを使いたい。捨てさせる案は嫌われた）
- 楽しい行動を、勝つための正しい戦略にする
- 全員が 7 点をつけるが誰も愛さないゲームは失敗する（尖らせる）
- シナジーはプレイヤーに発見させる
- 制約は創造性を生む
- 観客は問題を見つけるのは得意だが、解決は苦手（不満は聞き、直し方は自分で考える）

プレイヤー像：大きな瞬間を求める **Timmy**、自己表現を求める **Johnny**、勝って証明したい **Spike**。全員を同時に喜ばせようとしない。

## 複雑さと深さ
- **深さ ÷ 複雑さ** が高いカードが最良（Brode）。シンプルなカードの組み合わせから深いデッキが生まれる
- **レンティキュラー・デザイン**：初心者には単純、熟練者には深く見える。複雑さを「理解」「盤面」「戦略」に分け、前 2 つを低く保つ
- **NWO の目安**：入門・基本カードは場の他の 1 枚より多くに影響しない
- キーワードは 2 回目以降の読みを速くする。既知の概念に便乗した名前は説明の一部になる
- スマホでは画面の文字数が少ないほど読まれる（「8 語ルール」）。日本語 20〜30 字目安。**2 回説明が要るカードは作り直す**

## 勢力（派閥）
- **できないことで定義する**（MTG のカラーパイ：効果を勢力ごとに主・副・なしで割り当てる表を作る）
- 中心の動詞 1 つ＋意図的な弱点 1 つ＋勝ち方。3 行サマリーにして参照カード/選択画面に出す
- 勢力の個性はデッキ構築・組み合わせで大きく効かせ、プレイ中の複雑さは増やさない（Netrunner の方針）
- 2 勢力の組み合わせは人気が出やすい（ラヴニカの 2 色ギルド、Smash Up）
- **共通リソースの意味を勢力ごとに変える**（Smash Up の Madness：基本は不利だが一部の勢力は欲しがる）と、少ない追加ルールで差が出る
- 特定のカード群とだけ働く寄生的メカニクスは「程度の問題」。まとまったパッケージなら可

## コストカーブ（Schreiber の手順）
1. 効果をコストと利益に分ける
2. 共通の通貨で表す
3. 効果 1 つだけのカードから値を決める
4. 1 点だけ違うカード同士を比べて未知の値を逆算する
5. 合計して外れ値を探す
6. プレイテストで検証
- 選択式の効果は良いほうの選択肢を基準に値付け
- **迷ったら弱めに**（弱いカードは使われないだけ、強すぎるカードはゲームを壊す）
- 目標は「**すべてのカードに居場所がある**」。つまらないのにどこにでも入るカードは汎用性を理由に弱体化

## フィールバッド効果
- 打ち消し・手札破壊・資源破壊は「現在の機会を失う」痛みが大きい
- **否定ではなく遅延**にする（戻す・一時的に裏向き・次ラウンドまで止める）、失った分を補填する、重いコストを課す
- 勝率に影響がなくても体験の悪さは別に測る（Hearthstone の Discover は「答えを引けないと分かる無力感」を理由に変更）
