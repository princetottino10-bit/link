# おもしろさチェックリスト

設計の各段階で見返す。全部を満たす必要はないが、×が多い項目は理由を説明できるようにする。

## 決断
- [ ] 毎手番、少なくとも 2 つの「どちらも魅力的な」選択肢がある
- [ ] 正解が 1 つに決まる局面ばかりになっていない
- [ ] 短期（今の得）と長期（後の得）の取引がある

## 相互作用
- [ ] 相手の行動を見て自分の計画を変える場面がある
- [ ] 妨害に対する反撃・回避の手段がある
- [ ] 隠し情報があるなら、それを推理・ブラフする材料もある

## 緊張と逆転
- [ ] 決着の直前に「間に合うか」の駆け引きがある
- [ ] 負けている側にも逆転の筋がある（ただし勝っている側が損をするだけの補正にはしない）
- [ ] 終盤が序盤より盛り上がる

## 変化とリプレイ性
- [ ] 毎ゲーム、組み合わせや場の状況が変わる（派閥選択・ランダムなベースなど）
- [ ] 組み合わせごとに違う戦い方が生まれる
- [ ] 支配的な組み合わせ（これを選べば勝つ）がない

## 分かりやすさ
- [ ] 1 手番でやることを一文で言える
- [ ] 盤面を見れば、誰が勝っているか大体わかる
- [ ] カードのテキストは 2 行以内が基本
- [ ] 例外ルールはカードに書き、共通ルールは少なく保つ

## バランス
- [ ] 値（コスト）と効果の強さが反比例している
- [ ] 追加プレイ・追加ドローの連鎖が無限にならない
- [ ] 先攻有利が補正されている
- [ ] 1 ゲームの長さが目標に収まる（スマホ対戦なら 10〜15 分が目安）

## スマホで遊ぶなら
- [ ] 待ち時間が短い（1 手番 30 秒以内が目安）
- [ ] 画面 1 枚に盤面全体が収まる
- [ ] タップだけで全操作ができる
