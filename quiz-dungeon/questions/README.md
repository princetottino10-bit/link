# クイズダンジョン（仮）の問題集

系統（10）ごとに1ファイル。企画書の「問題に付ける情報」と、熟練度で開くヒント（文字数・はずれ候補を2つ消す・1文字目）がどの問題でも出せる形にしてある。

| ファイル | 系統 |
| --- | --- |
| anime.json | アニメ・漫画 |
| game.json | ゲーム |
| sports.json | スポーツ |
| music.json | 音楽 |
| movie.json | 映画・ドラマ・特撮 |
| history.json | 歴史・文化 |
| geo.json | 地理・旅 |
| science.json | 科学・自然 |
| food.json | 食・暮らし |
| words.json | ことば・テクノロジー |

系統のキー（`anime` など）は名乗りの試作（`nanori-test.html`）の `GENRES` と同じ。

## 1問の形

```json
{
  "id": "sports-012",
  "genre": "サッカー",
  "level": "mania",
  "q": "1990年代から2017年までASローマ一筋でプレーし、…フランチェスコ・何？",
  "answer": "トッティ",
  "yomi": "とってぃ",
  "wrong": [["デル・ピエロ", "でるぴえろ"], ["マルディーニ", "まるでぃーに"], ["ネスタ", "ねすた"]],
  "note": "2006年のW杯ではイタリアの優勝に貢献した。",
  "source": "claude"
}
```

| 項目 | 中身 |
| --- | --- |
| `id` | `系統-連番`。一度付けたら変えない（成績や図鑑の記録に使う） |
| `genre` | 系統の中の細かいジャンル。二つ名（「セリエAの鬼」など）の材料 |
| `level` | `normal`（ふつう）か `mania`（マニアック） |
| `q` | 早押しで1文字ずつ出す問題文。「？」で終える |
| `answer` | 正解の表記（画面に出す） |
| `yomi` | 文字パネルで入れる読み。ひらがなと「ー」だけ。文字数ヒントと1文字目ヒントはここから作る |
| `alt` | 正解にしてよい別の読み（任意） |
| `wrong` | はずれ候補3つ。`[表記, 読み]`。候補を2つ消すヒントや4択表示、文字パネルのおとりの文字に使う |
| `note` | 解説。正解発表のあとに出す |
| `source` | 作った人。`claude`、`local-llm` など |

## 書くときの決まり

- はずれ候補は、答えと同じ種類で紛らわしいものにする（人名なら人名、同じ作品の別キャラなど）
- 「〜何？」の形で、答えるのは問題文の続きになる部分だけにする（例：「フランチェスコ・何？」→ トッティ）
- 読みの1文字目は小さい文字や「ー」にしない（1文字目ヒントが成り立たないため）
- 実在の人物・作品を扱ってよいが、事実は確かめてから入れる

## チェック

```
node quiz-dungeon/questions/check.mjs
```

形式の誤り（読みにカタカナが混ざる、はずれ候補が3つない、id の重複など）があると止まる。系統ごとの問題数も出る。
